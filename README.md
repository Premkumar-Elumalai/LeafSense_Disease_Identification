# LeafSense: Plant Disease Analysis Framework

LeafSense is a computer-vision-based framework for plant disease classification, pixel-level lesion segmentation, and lesion coverage estimation using DenseNet-121 and U-Net.

## Research Components

- Plant disease classification using DenseNet-121.
- Pixel-level lesion segmentation using U-Net.
- Image-derived lesion coverage estimation.
- Experimental evaluation and performance analysis.
